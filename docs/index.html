Architecture

四道 Gate 质量门禁 & 三条 Lane 泳道

每一份输出在交付前必须通过严格的门禁系统拦截与结构化约束

GATE 1

G1 事实分类闸

提取并锁定基础事实，严格区分 Confirmed（已证实）、Alleged（主张）、Disputed（争议）与 Missing（缺失），严禁直接推定。

GATE 2

G2 法源闸

按法律位阶（L1-L4）核验法源有效性，严禁虚构未出台法规，条号均带〔条号未核验〕标记，触发 M2 案号绝对禁令。

GATE 3

G3 证据闸

构建争点与证据逐项映射矩阵，执行四元 min 规则，在保密措施或规章制度等关键证据不足时，强制下调结论确定性。

GATE 4

G4 交付闸

装配标准化 Review Basis 抬头，回答商业落地七问，生成待核验清单，确保输出与 12 个强约束 JSON Schema 100% 对齐。
