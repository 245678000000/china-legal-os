Paradigm Shift

告别单体 Prompt 幻觉，回归严谨法务工作流

深度对比通用大模型单体 Prompt 与 China Legal OS 在真实企业法务场景下的质感差异

普通单体 Prompt / 法律问答
  • 顺着用户主张产生幻觉 用户说“前员工窃取了商业秘密”，AI 顺着直接定性并给出起诉建议，忽视保密措施三要件。
  • 虚构裁判文书与案号 自行编造看似真实的最高院民终案号，造成极度危险的法律虚假引用。
  • 空洞无用的合规套话 通篇输出“存在一定法律风险，建议咨询当地专业律师”，缺乏任何商业可行性落地路径。
China Legal OS 模块化工作流
  • 严格事实分类与要件重构 区分 Confirmed 事实与 Alleged 主张，以事实为唯一依据重新拆解法定构成要件。
  • M2 案号绝对禁令与检索指引 0 虚拟案号强正则拦截，条号标注〔条号未核验〕，输出人民法院案例库检索指引。
  • 商业落地七问与可执行方案 明确最不坏路径、退让底线 (Fallback)、审批升级矩阵与今日具体执行责任人。
Quality Gates

四道 Gate 质量门禁体系

全流水线严密拦截，确保每一份法务交付物 100% 严谨可靠

GATE 1

G1 事实分类闸

锁定基础事实，严格分离已证实事实、单方主张与缺失事实，严禁顺着情绪化主张直接定性。

GATE 2

G2 法源等级闸

按法律位阶（L1-L4）核验法源有效性，严禁虚构未出台法规，条号标注〔条号未核验〕，触发 M2 案号禁令。

GATE 3

G3 证据核验闸

构建证据逐项映射矩阵，执行四元 min 规则：min(法律, 证据, 事实, 法源)，关键证据缺失时强制下调确定性。

GATE 4

G4 交付质量闸

装配 Review Basis 抬头，回答商业落地七问，生成待核验清单，与 12 个强约束 JSON Schema 100% 对齐。
