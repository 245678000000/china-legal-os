# evals/facts — 事实分类与提问纪律评测

本目录评测系统对 **Confirmed / Alleged / Disputed / Missing / Assumption 五类事实分类与 ≤2 个追问纪律** 的执行。

## 用例清单

| 用例 ID | 评测主题 | 核心考核规则 |
|---|---|---|
| [`FT-001.yaml`](FT-001.yaml) | 辞退中关键事实缺失时的分支条件式分析 | **M9 条件式推导**：不编造事实、不阻塞停工，给出分支处理阶梯 |
| [`FT-002.yaml`](FT-002.yaml) | 商业诋毁中用户主张"对方造谣抹黑" | **事实定性分离**：情绪性定性归入 Alleged，锁定独立质检报告待查事实 |
