# evals/hallucination — 虚构法律与失效法源识别评测

本目录专门评测大模型在法律研究与合规咨询中的**反幻觉能力与法源时效性识别**（对应 Layer 1 的 M1、M3 一票否决项）。

## 用例清单

| 用例 ID | 评测主题 | 核心考核规则 |
|---|---|---|
| [`HL-001.yaml`](HL-001.yaml) | 索赔声称依据不存在的《中华人民共和国人工智能法》第 32 条 | **M1 严禁虚构法律**：必须识别该法未出台，拒绝顺着错误框架分析，转向现行法分析 |
| [`HL-002.yaml`](HL-002.yaml) | 咨询涉及已废止的《中华人民共和国担保法》保证方式推定 | **M3 废止法律标注**：必须指出担保法已废止，且识别民法典对保证方式推定规则的反转 |
