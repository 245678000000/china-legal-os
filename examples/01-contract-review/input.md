# 案例 01：合同审查 — 原始输入与材料

## 1. 用户提问
```
对方发来了一份《大数据技术服务采购协议》，我们是买方（甲方），合同金额总共 150 万元。请帮我们法务团队全量审查这份协议，指出里面的红线和隐藏风险，做必要的数值测算，并提供可直接用来谈判修改的条款和向分管副总裁汇报的简报。
```

## 2. 附件合同片段文本
```markdown
大数据技术服务采购协议

甲方（采购方）：北京知远数据科技有限公司
乙方（服务方）：华东云智信息系统有限公司

第一条 服务内容与交付
1.1 乙方为甲方定制开发并部署大数据分析平台（以下简称“目标系统”）。
1.2 乙方应在合同签署后 90 个自然日内完成系统上线并交付甲方初审。

第二条 费用与支付
2.1 合同总金额为人民币 150 万元整（含税）。
2.2 支付进度：
    (1) 本协议生效后 5 个工作日内，甲方向乙方支付预付款 30%（45 万元）；
    (2) 系统上线部署完毕且乙方开具全额增值税专用发票后 5 个工作日内，甲方向乙方支付进度款 60%（90 万元）；
    (3) 系统质保期（1 年）届满后支付尾款 10%（15 万元）。

第三条 知识产权归属
3.1 乙方在履行本协议过程中形成的所有技术成果、源代码、算法模型、文档及衍生知识产权，其所有权均独家归属于乙方。
3.2 甲方仅享有在自有业务范围内非排他、不可转让的普通使用许可。

第四条 违约责任与责任限制
4.1 乙方迟延履行的违约金：若乙方逾期交付目标系统，每逾期一日，应按合同总金额的万分之五向甲方支付迟延履行违约金，但乙方累计承担的违约金总额不超过合同总金额的 20%。
4.2 责任上限：无论基于何种违约、侵权或违反应尽义务，乙方对甲方所承担的全部直接赔偿责任总额在任何情况下均不得超过本合同甲方实际已支付服务费用的 10%。乙方不对甲方的任何间接损失、可得利益损失承担责任。
4.3 单方解除权：若甲方未按第二条约定期限支付任何一期款项逾期超过 5 个工作日，乙方有权单方书面通知解除本合同，甲方应向乙方支付合同总金额 30% 的解约违约金。

第五条 争议解决
5.1 本协议未约定争议管辖法院。
```
