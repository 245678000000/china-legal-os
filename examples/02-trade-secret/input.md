# 案例 02：商业秘密维权 — 原始输入与材料

## 1. 用户提问
```
我们是一家自动驾驶科技公司。上个月底，我们前感知算法负责人李某离职加入了直接竞争对手公司。今天我们的 IT 安全团队在做离职追溯审计时，发现李某在离职前两周，利用管理员权限从服务器上批量下载了核心未公开算法模型的全套源代码和训练数据集（约 80GB）。李某入职时签过保密协议，离职时也签署了《离职承诺书》声明已交接并销毁所有公司数据。我们能做什么？如何防止代码泄露？能否追究李某和新公司的法律责任？
```

## 2. 附件材料清单
- 附件 1：《保密与知识产权归属协议》（李某签字版原件，含保密信息定义、脱密期要求及 50 万元保密违约金）
- 附件 2：《员工离职交接与承诺书》（李某签字版，承诺已删除全部个人设备上的公司资料）
- 附件 3：IT 安全团队审计日志（显示李某账号于 2026 年 7 月 15 日 23:14 通过 VPN 下载代码仓库压缩包）
