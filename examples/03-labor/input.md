# 案例 03：劳动解除 — 原始输入与材料

## 1. 用户提问
```
我们是一家互联网公司。公司某市场部主管张某入职满 3 年，月薪 15,000 元。上周刚刚完成第三季度绩效考核，张某的考核结果为 D（不合格）。部门总监要求 HR 部门今天下午立即向张某发出辞退通知书，不给任何经济补偿。理由是公司《员工手册》第 4.2 条写明：“员工在一个自然年内单季度考核不合格者，公司有权立即解除劳动合同且无需支付任何经济补偿金。” 请问公司能否直接开除？有哪些法律风险？如果必须开除，HR 应该怎么操作并计算补偿？
```

## 2. 附件材料
- 材料 1：《劳动合同》（固定期限3年，已续签一次，岗位：市场主管）
- 材料 2：《员工手册》（第 4.2 条规定单次考核不达标可解除，但未提供员工签收回执及民主制定程序纪要）
- 材料 3：2026 年 Q3 绩效考核打分表（部门总监单方打分 D，张某拒绝在考核结果上签字）
