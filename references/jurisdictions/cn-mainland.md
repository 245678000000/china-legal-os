# Jurisdiction Frame — 中华人民共和国大陆地区

**本文件不放法条正文。** 内联法条清单会变成"看起来像已核验的引用"，且不会自动更新（见 `docs/ARCHITECTURE_REPORT.md` §B4）。这里只放**体系框架**和**检索路径**。

---

## 1. 法律渊源层级

```
宪法
  └─ 法律（全国人大及其常委会）
       └─ 行政法规（国务院）
            └─ 部门规章（国务院各部委）／ 地方性法规（地方人大）
                 └─ 地方政府规章
```

**司法解释**（最高人民法院、最高人民检察院）在实务中具有直接适用性，检索时必须与对应法律一并查。

**指导性案例**具有参考效力，不是正式法律渊源。**人民法院案例库**入库案例在类案检索中有实务意义。二者在 `RETRIEVAL_MODE: none` 下**均不得由 OS 自行产出**（R3）。

**规范性文件、监管问答、窗口指导**不是法律渊源，但在合规判断中影响实际执法口径 —— 属于 Currency Trigger 范围（R4），必须核验。

## 2. 法院体系

基层 → 中级 → 高级 → 最高人民法院
专门法院：知识产权法院、互联网法院、金融法院、铁路运输法院

管辖判断影响：诉讼成本、审理周期、地方保护、上诉路径、执行难度。争议模块必须评估。

## 3. 争议解决路径

诉讼 · 仲裁（机构仲裁为主，需有效仲裁协议）· 劳动仲裁（多数劳动争议的**前置程序**）· 行政复议与行政诉讼 · 调解。

选择路径时的实务变量：一裁终局 vs 两审终审、保全可行性、执行便利、保密性、周期、费用。

## 5. 地方差异

以下问题**必须**确认适用地，不得给全国统一答案：

- 劳动：最低工资、社保基数、加班认定口径、经济补偿计算基数上限、竞业限制补偿标准
- 诉讼：立案口径、级别管辖标的额标准、保全担保要求
- 行政：地方备案与许可要求、执法尺度
- 部分行业准入与经营要求

地方性依据的检索入口：当地人大、当地政府、当地人社局/市场监管局官网，以及当地高院的审判指引。后者通常无公开统一入口，属于 `[缺口]`，应在待核验清单中标出。

## 6. 时间维度

分析必须锚定 `relevant_time`：

- 行为发生时有效的法律 vs 现在有效的法律
- 法律修订与新旧衔接（尤其近年修订的公司法、民诉法、公司法时间效力规定）
- 时效起算点
- 合同签订时 vs 履行时的规则变化

**Currency Trigger（R4）在此处最容易被违反。** 涉及"是否现行有效""什么时候生效""有没有新规"时，结论强度上限 `Conditional`。
