# Source Policy

法源怎么用、怎么标、什么时候必须停下来。所有涉及法律依据的输出都受本文件约束。

---

## 0. 配置块（用户可编辑）

```yaml
RETRIEVAL_MODE: none        # none | web | database
RETRIEVAL_SOURCES: []       # 例：[北大法宝 MCP, 元典, 联网搜索]
LAST_PREFLIGHT: null
```

Gate 行为绑定 `RETRIEVAL_MODE`，不是硬编码。当前值为 `none`，§3 的五条硬规则全部生效。

**切换到 `web` / `database` 时**：启用 §6 的 preflight 探测；探测失败自动降级回 `none` 的行为，并在交付物抬头写明"检索源探测失败，已降级"。

---

## 1. 两个正交维度

把"这条规则本该由谁支撑"和"这次我实际拿到了什么"分开，否则无法判定 G2。

### 法源等级 Authority Level

| Level | 内容 | 用途 |
|---|---|---|
| **L1** | 用户提供的原始材料（合同、邮件、制度、聊天记录、用户上传的法规文本） | **用于确定事实**。材料里的法律观点不因为在材料里就获得权威性 |
| **L2** | 官方法律来源：法律、行政法规、部门规章、司法解释、监管规则、地方性法规 | 法律结论的主要依据 |
| **L3** | 官方司法案例：人民法院案例库、指导性案例、最高法公报、官方典型案例、可核验裁判文书 | 佐证适用口径 |
| **L4** | 辅助材料：商业数据库、学术论文、专业书籍、律所文章、机构研究 | **参考，不能替代 L2/L3**。不得作为法律依据陈述 |

### 核验状态 Verification Status

| Status | 触发 |
|---|---|
| `verified` | 内容来自用户提供的官方文本，或来自实际连通的检索源返回 |
| `unverified` | 来自模型知识。**`RETRIEVAL_MODE: none` 下 L2/L3/L4 的默认且几乎唯一状态** |
| `contradicted` | 与用户材料或另一来源冲突 |

### 禁止 promotion

不得因为某条引用"看起来是对的"、"我很确定"、"这是常识"就把 `unverified` 改成 `verified`。

> **标签描述这次实际发生了什么，不描述你有多确信。**

`unverified` 不是羞耻标记，它只是诚实地说"这来自模型知识"。把它标成 `verified` 才是错误——那是把读者的核验责任偷偷取消了。

## 2. 来源标签（六个）

输出中的实质依据必须带标签：

| 标签 | 用于 |
|---|---|
| `[材料]` | L1。后面跟文件名/页码/条款号 |
| `[官方法源]` | L2。当前模式下必然伴随 `-未核验` |
| `[官方案例]` | L3。当前模式下**只能来自用户材料**，否则违反 R3 |
| `[辅助]` | L4 |
| `[模型知识-未核验]` | 无独立来源的陈述 |
| `[缺口]` | 需要但没有 |

## 3. 无检索源下的五条硬规则

### R1 — 条号必须带未核验标记

```
《中华人民共和国劳动合同法》第 24 条〔条号未核验〕
```

制度层面的陈述（"竞业限制期限最长不超过两年"）相对可靠；**具体条号是最高幻觉风险项**，必须显式标注。

### R2 — 条号不得作为唯一支撑

一个法律结论如果只有"第 X 条"支撑，而该条的**规则内容**没有被独立、可理解地陈述出来，结论降级至 `Conditional` 并进入待核验清单。

理由：条号错了很难被发现，规则内容错了法务一眼能看出来。**写规则内容比写条号更负责任。**

❌ `依据《公司法》第 148 条，董事不得自我交易。`
✅ `公司法对董事与公司之间的自我交易设有限制，通常需要经股东会或董事会依章程批准，未经批准的收入可能被要求归入公司。[官方法源-未核验]（《中华人民共和国公司法》，条号未核验，需核验）`

### R3 — 案号绝对禁令

**不得自行产出任何案号、案件名称、法院名称组合或裁判要旨。** 案例只能来自 L1 用户材料。

需要案例支撑时，输出**检索指引**：

```
【检索指引】
目标：竞业限制违约金约定过高时，法院酌减的常见幅度
平台：人民法院案例库 rmfyalk.court.gov.cn ｜ 中国裁判文书网 wenshu.court.gov.cn
检索词：竞业限制 违约金 调减 ｜ 竞业限制 违约金 过高 酌减 ｜ 竞业限制 违约金 三倍
想找到：与本案岗位层级、薪酬量级相近的案件中，判决支持的违约金区间
找到后会改变：违约金主张金额的预期，以及是否值得诉讼
```

这条规则是二元的、可正则检测的，是当前模式下最强的一条反幻觉约束。

### R4 — Currency Trigger 五类封顶

以下五类内容，结论强度上限 `Conditional`，且必须写明"以核验为准"：

1. 法律法规的**生效日期**
2. **修订状态与现行有效性**（是否已被修正、废止、替代）
3. **监管口径与执法姿态**
4. **最新司法解释**
5. **司法实践倾向**

模型知识在这五点上系统性过期。

### R5 — 待核验清单

每份 Lane B/C 交付物必须包含：

| # | 待核验项 | 类型 | 建议核验入口 | 核验不通过的影响 |
|---|---|---|---|---|
| 1 | 《劳动合同法》竞业限制条款的条号 | 条号 | flk.npc.gov.cn | 条号有误但规则成立 → 仅更正引用，结论不变 |
| 2 | 该地方性规定是否现行有效 | 时效 | 发布机关官网 | 若已废止 → 结论作废，需重做 |
| 3 | 违约金酌减的司法倾向 | 实践倾向 | rmfyalk.court.gov.cn | 影响金额预期，不影响是否维权 |

**"核验不通过的影响"是最重要的一列**——它把一张待办清单变成风险分级表，让法务知道先核哪一条。按影响严重程度排序，不按出现顺序排序。

## 4. 官方核验入口

2026-08-19 实测可达（`gsxt` 除外）：

| 用途 | 入口 |
|---|---|
| 法律 / 行政法规 / 地方性法规 / 司法解释 | 国家法律法规数据库 `flk.npc.gov.cn` |
| 行政法规 / 国务院文件 | 中国政府网 `www.gov.cn` |
| 司法解释 / 公报 | 最高人民法院 `www.court.gov.cn` |
| 入库案例 | 人民法院案例库 `rmfyalk.court.gov.cn` |
| 裁判文书 | 中国裁判文书网 `wenshu.court.gov.cn` |
| 执行信息 | 中国执行信息公开网 `zxgk.court.gov.cn` |
| 检察规则 / 典型案例 | 最高人民检察院 `www.spp.gov.cn` |
| 市场监管 / 反不正当竞争 / 广告 | 国家市场监督管理总局 `www.samr.gov.cn` |
| 网络与数据 | 国家网信办 `www.cac.gov.cn` |
| 劳动与社保 | 人力资源社会保障部 `www.mohrss.gov.cn` |
| 专利 / 商标 | 国家知识产权局 `www.cnipa.gov.cn` |
| 主体资格 / 经营异常 | 国家企业信用信息公示系统 `www.gsxt.gov.cn`（境外网络可能不可达） |

## 5. L1 材料的特别规则

**用户材料用于确定事实，不用于确定法律。**

用户邮件里写"根据竞业协议第 5 条他已构成违约"：
- `[材料]` 能支撑的是：**用户主张他违约**（`alleged`）
- `[材料]` 不能支撑的是：**他违约**（这是待证的法律定性）

用户上传的法规文本是例外——那属于 L2 且状态可标 `verified`，但需确认版本与来源（哪里下载的、什么时候的版本）。

---

## 6. Preflight（`RETRIEVAL_MODE` ≠ none 时启用）

配置了检索源 ≠ 检索源在工作（API key 过期、服务下线、网络问题）。因此：

1. 首次引用前发一个**已知答案**的测试查询
2. 未返回有效结果 → 在输出的来源行写明"检索源未连通，以下依据来自模型知识，使用前须核验"，并按 `none` 模式的全部规则执行
3. 返回有效结果 → 正常标 `verified`，并记录 `LAST_PREFLIGHT`

不做 preflight 就引用，等于在用户完全不知情的情况下输出了模型记忆。

`RETRIEVAL_MODE: none` 时**不做** preflight（没有可探测的对象），直接按 §3 执行。

## 7. G2 法源闸判定

输出法律结论前逐条检查：

```
[ ] 每个法律结论有 authority 标注（名称 + 规则内容 + Level + Status）
[ ] 出现的每个条号都带〔条号未核验〕
[ ] 每个条号都进了待核验清单
[ ] 没有条号是唯一支撑（R2）
[ ] 不存在非 L1 来源的案号 / 案件名称 / 裁判要旨（R3）— BLOCKED 级
[ ] 命中 Currency Trigger 的结论强度 ≤ Conditional（R4）
[ ] L4 材料没有被当作法律依据陈述
```

R3 命中 → **BLOCKED**：删除该案号，改写为检索指引，然后继续。
其余命中 → 自动补标注或自动降级，记入 QA 日志，继续。
